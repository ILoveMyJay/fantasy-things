📌 使用指南与技巧
Notice: Google Flow can update its UI frequently. Please check the notice icon before long runs.
  1. Flow homepage URL: flow.google.com (click to open)
  2. Click the inverted-triangle filter icon (top right), then deselect all filters.
  3. In the filter, set Sort by to 'Newest'.
  4. In Flow's initial settings, set 'Clear prompt on submit' → 'On'.
  5. Select your desired mode and proceed. (Script-to-Image / Factory mode recommended)
  6. If Factory doesn't work: Top-right ⋮ → Translate → Don't translate this site
  7. If 'Content Script injection failed' occurs, go to chrome://extensions/ → AI4Next Details →
       # Enable 'Allow access to the following sites'
       # Enable 'Allow access to file URLs'
  8. If files aren't saved to the designated folder or filenames aren't generated by prompt number, disable other extensions. (Extension path conflicts are the cause.)
✨ Frequently Asked Questions

Q. Script analysis doesn't generate prompts!

→ When using Gemini free key, key usage may be limited during peak hours. Switch to a different free model in settings and retry.

→ Daily API key quota may be exhausted. Register a new API key from another account, or get a paid API key (smarter model).

Q. Custom character reference doesn't work properly!

→ When using individual prompts (not auto-script mode), the custom character's naming or main/sub character codes (MCR/SC1/SC2 etc.) must be included in the prompt for matching.

→ Script-to-Image / Factory modes auto-detect main/sub characters via AI, but the character names in your script must match your registered naming.
