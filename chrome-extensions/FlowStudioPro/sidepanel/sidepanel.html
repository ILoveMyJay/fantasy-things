✨ 常见问题与解答

问：剧本解析提示词无反应？

→ 请在右上角设置中填入有效的 Gemini API Key。免费 Key 在高峰期可能触发限流，可在设置中切换至 Gemini 3 Flash 模型重试。

问：角色定妆图和分镜如何确保在同一个项目？

→ 本扩展已升级闭环引擎。在画板生成角色后，直接点击「批量渲染」，扩展将自动锁定当前画板，杜绝跳回首页与重复上传。
