## 一、系统总览与量化方法论基础

### 1.1 三层大盘架构 + 解耦式个股闸门
本系统把复杂的 A 股交易拆成互不干扰、各司其职的四道防线：
- **L1 纠偏战略罗盘（定 2~8 周主波段与大盘总仓位）**：用周/日技术趋势轴 + 3 路正交确认因子（ERP / 期权 PCR / 期指滚仓基差）+ 非对称缓冲器（Hysteresis），给出五档仓位（`0% / 20% / 30% / 40~50% / 100%`）。
- **L2 战术拐点引擎（抓 V 底、防冲顶、看催化）**：监控极端恐慌左尾试仓、冲顶暴走封顶、大阳线中轨 `3/4` 蓝灯与 7×24 实时新闻雷达。
- **L3 双创风格与 49 行业轮动**：针对高弹性的科创 50 / 创业板做专属拥挤度风控（如 `TCR > 40%` 放量滞涨压仓），并定位当下资金主线。
- **Phase 2 个股趋势与买前风控闸门（解耦）**：个股不反过来影响大盘判断，但**单向受限于 L1 大盘总仓位上限**（大盘空仓 `0%` 时，再好的个股也强制拦截 `VETO`）。

### 1.2 四个必须懂的量化铁律概念

| 概念 | 通俗解释 | 为什么极度重要 |
| :--- | :--- | :--- |
| **零未来数据（Zero-Lookahead / 因果性）** | 在第 `T` 天做决策时，只能用 `≤ T` 时刻**真实已经公开**的数据，绝对不能偷看后面几天的价格或周五收盘价。 | 很多网上“高胜率回测”在周二就偷用了本周五的周线收盘价，或者在 15:00 收盘时偷用了次日凌晨才收盘的美债收益率，一上实盘立刻失效。 |
| **T+1 披露滞后（Disclosure Lag）** | 两融余额、官方期权 PCR、宽基 ETF 份额、ERP 等数据在 15:00 闭市瞬间尚未发布，通常在晚间或次日早盘才披露。 | 因此当日 14:45/15:00 决策时，这类数据必须严格使用前一日（`T-1`）数值；本系统用 `module_dates` 自动区分“正常 T-1 滞后”与“跨日污染”。 |
| **Walk-Forward 样本外验证（IS → OOS）** | 把历史切两段：前半段 **IS（样本内，如 2021–2023）** 设计规则，后半段 **OOS（样本外，如 2024–2026）** 锁死参数盲测。 | 防止“看着答案编公式”。只有在熊市（2021–2023）和震荡牛市（2024–2026）双体制下都有效的因子才值得保留。 |
| **参数高原 vs 单点过拟合** | 好策略在参数微调时表现平缓（如缓冲天数 `K=2, 3, 5` 收益都在 `+15%~16%`），这叫**参数高原**；只在某一个诡异数字（如 `K=3.17`）才赚钱就是过拟合。 | 实盘环境千变万化，只有处在参数高原上的低自由度规则才扛得住未来市场变化。 |

## 二、L1 主趋势轴：多周期技术指标

核心思想：**周 K 定中期大方向（上证 + 沪深300），日 K 找入场与离场时机**；绝不把高波动的科创/创业板混入大盘总仓位主轴。

### 2.1 一目均衡表（Ichimoku Cloud，参数 `9 / 26 / 52`）
- **是什么**：一套把“趋势方向 + 支撑阻力带”合二为一的经典图表系统，核心是前移 26 根 K 线画出的**云层（Cloud）**。
- **核心公式**：
  - 转换线（短周期中轴）：$\text{Tenkan} = \frac{\max(H_9) + \min(L_9)}{2}$
  - 基准线（中周期中轴）：$\text{Kijun} = \frac{\max(H_{26}) + \min(L_{26})}{2}$
  - 先行带 A（向右平移 26 根）：$\text{Span A}_t = \frac{\text{Tenkan}_{t-26} + \text{Kijun}_{t-26}}{2}$
  - 先行带 B（向右平移 26 根）：$\text{Span B}_t = \frac{\max(H_{52, t-26}) + \min(L_{52, t-26})}{2}$
  - 云层上沿 = $\max(\text{Span A}, \text{Span B})$，云层下沿 = $\min(\text{Span A}, \text{Span B})$
- **怎么看**：
  - `ABOVE_CLOUD`（价格在云层上方）：多头主导（`+1.0` 分），云层变支撑；
  - `IN_CLOUD`（价格在云层内部）：多空胶着震荡（`0.0` 分）；
  - `BELOW_CLOUD`（价格在云层下方）：空头主导（`-1.0` 分），云层变强压力，反复尝试突破云层失败称为“出云受阻”。

### 2.2 VW-MACD（成交量加权 MACD，参数 `12 / 26 / 9`）
- **是什么**：传统 MACD 只看收盘价，主力在缩量阴跌中拉几根无量阳线就能“画金叉骗人”。VW-MACD 先用成交量给每天价格加权（**VWMA**），没量的假反弹根本拉不动指标。
- **核心公式**：
  $$\text{VWMA}_N(t) = \frac{\sum_{i=t-N+1}^{t} \text{Close}_i \times \text{Volume}_i}{\sum_{i=t-N+1}^{t} \text{Volume}_i}$$
  $$\text{DIF} = \text{VWMA}_{12} - \text{VWMA}_{26}, \quad \text{DEA} = \text{EMA}_9(\text{DIF})$$
- **四态判定**：
  - `BULL_ABOVE_ZERO`（`DIF > 0` 且 `DIF >= DEA`）：零轴上强势多头（`+1.0`）；
  - `WEAKENING_ABOVE_ZERO`（`DIF > 0` 但 `DIF < DEA`）：多头转弱（`+0.5`）；
  - `WEAK_REBOUND_BELOW_ZERO`（`DIF < 0` 但 `DIF > DEA`）：零轴下弱反抽，警惕死猫跳（`-0.5`）；
  - `BEAR_BELOW_ZERO`（`DIF < 0` 且 `DIF <= DEA`）：零轴下主跌空头（`-1.0`）。
- **真实案例**：`2026-09-22` 上证反弹到 `3952`、沪深 300 摸到 `4544`，表面看似横盘蓄势，但上证与沪深 300 的**周线 VW-MACD 始终死死压在零轴下方**（`-93.25` / `-109.37`），直接定性为熊市反抽，随后暴跌 `-14%`。

### 2.3 布林带（Bollinger Bands, `20, 2`）与 MA20 乖离率
- **公式**：
  - 中轨 $\text{MA}_{20} = \text{Mean}(\text{Close}_{20})$，标准差 $\sigma_{20} = \text{Std}(\text{Close}_{20})$
  - 上轨 = $\text{MA}_{20} + 2\sigma_{20}$，下轨 = $\text{MA}_{20} - 2\sigma_{20}$
  - 轨道相对位置：$\%B = \frac{\text{Close} - \text{下轨}}{\text{上轨} - \text{下轨}}$（`>0.85` 偏热，`<0.15` 超卖）
  - **MA20 乖离率**：$\text{Ext}_{20} = \left(\frac{\text{Close}}{\text{MA}_{20}} - 1\right) \times 100\%$
- **实战用法**：本系统用 `Ext_20` 做**位置护栏**——大盘 `> +8%` 触发冲顶过热警惕（如 `2024-10-08` 高达 **`+26.59%`**），个股 `> +12%` 触发 Phase 2 追高红灯 `VETO`（如 `2026-11-27` 中芯国际单日大涨后偏离 `+17.6%`）。

### 2.4 CCI（顺势指标, 14）与顶底背离
- **公式**：典型价格 $TP = \frac{H + L + C}{3}$，$\text{CCI} = \frac{TP - \text{MA}_{14}(TP)}{0.015 \times \text{MD}_{14}}$（$\text{MD}_{14}$ 为平均绝对偏差）。
- **背离含义**：近 12 根 K 线价格创出新高，但 CCI 高点反而比前 13 根明显低（下降超 15 点），称为**顶背离**（动能衰竭，扣 `-1.0` 分）；反之价格创新低而 CCI 抬高为**底背离**（加 `+1.0` 分）。

## 三、L1 正交确认分：宏观估值与衍生品聪明钱

光看技术面容易在震荡市被骗线，因此需要 3 路与技术面**低相关性（正交）**的确认因子辅助裁决（总权重 `3.5`）。

### 3.1 股债息差 ERP（Equity Risk Premium）与 750 日滚动 Z-Score
- **是什么**：衡量“买股票比买 10 年期无风险国债多赚多少预期回报”。ERP 越高，说明股市相对债市越便宜、越有安全边际。
- **公式**：
  $$\text{ERP} = \frac{1}{\text{沪深300 PE}_{\text{TTM}}} - \text{中国10年期国债收益率}$$
  $$Z_t = \frac{\text{ERP}_t - \mu_{750}}{\sigma_{750}}$$
  （其中 $\mu_{750}, \sigma_{750}$ 为过去约 3 年 750 个交易日的均值与标准差。）
- **实证规则（非对称设计）**：
  - **$Z \ge +1.5\sigma$ → 强多锚 (`+1.0`，权重 `1.5`，单独贡献 `+42.9` 分)**：5 年回测最强中期底锚！样本内（2021–2023）未来 60 日均值 `+4.93%`（胜率 `75.9%`），样本外（2024–2026）未来 60 日均值 **`+14.72%`（胜率 `100%`）**；
  - **$Z \le -1.2\sigma$ → 温和警示 (`-0.5`，单独贡献 `-21.4` 分)**：因为 `-21.4 > -25.0`，**绝不会单票否决健康牛市**（避免在 2025 慢牛里因为估值稍高就提前清仓），只有当 PCR 或基差同步恶化时才合谋降仓；
  - **已剔除 `0.8σ ≤ Z < 1.5σ`**：Phase 0 实证该区间在 2021–2023 熊市里反复接飞刀（60D `-3.64%`，胜率仅 `26.5%`）。

### 3.2 官方 50 / 300 ETF 期权 PCR（Put / Call Ratio）
- **是什么**：认沽（看跌）期权成交量 ÷ 认购（看涨）期权成交量，反映机构在期权市场的避险恐慌或乐观情绪。
- **公式**：
  $$\text{PCR}_t = \frac{\text{PutVol}_t}{\text{CallVol}_t} \times 100\%, \quad \text{PCR\_EMA5} = \text{EMA}_5(\text{PCR})$$
  再计算当前 `PCR_EMA5` 在过去 60 个交易日中的历史分位（0%~100%）。
- **实证纠偏（极性反转 + 假底否决）**：
  - **为什么旧版写反了？** 教科书常误以为 PCR 低=看涨、PCR 高=看跌；但 5 年因果实测显示 50/300 PCR 与未来 5 日收益呈显著**正相关**（IS 与 OOS 同向为正！）：
    - **双高恐慌对冲**（50分位 `≥80%` 且 300分位 `≥75%`）：说明大家吓坏了疯狂买看跌期权对冲，往往是短期情绪低点 → 逆向加分 **`+0.5`**；
    - **双低自满区**（50分位 `≤20%` 且 300分位 `≤25%`）：大家都乐观抢购认购期权 → 过热温和警示 **`-0.5`**；
  - **保留“50 领先 300 假底否决”（`BEAR_DIVERGENCE`, `-1.0`）**：当 300 PCR 跌破 `20%` 下轨、但权重龙头 50 PCR 仍高于 `30%` 时，代表大资金并未在核心权重见底，IS/OOS 均偏弱，一票扣 `-1.0`。

### 3.3 中金所股指期货（`IH / IF / IC / IM`）与纯净滚仓年化基差
- **四大品种对照**：
  - `IH` = 上证50（超大盘蓝筹） | `IF` = 沪深300（核心大盘） | `IC` = 中证500（中盘） | `IM` = 中证1000（中小盘成长，**2022-07-22 上市**）。
- **核心公式**：
  $$\text{基差} = \text{期货价} - \text{现货指数价}$$
  $$\text{年化升贴水率} = \frac{\text{基差}}{\text{现货价}} \times \frac{365}{\text{距交割日自然天数}} \times 100\%$$
  - 基差 `< 0` 叫**贴水**（期货比现货便宜，常见于对冲盘抛压或分红除息预期）；基差 `> 0` 叫**升水**（多头抢筹）。
- **为什么必须“纯净滚仓（`roll_days = 5`）”？**
  - 中金所合约每月**第三个周五**交割。临近交割（剩余天数 `≤ 5` 天）时，公式分母“距交割日天数”趋近 1，极微小的价差会被乘以 `365/1` 放大成几十倍噪音！因此距交割 `≤ 5` 天必须自动切换至**次月合约**计算连续基差。
- **实证两大升级**：
  1. **用 `IM / IC` 替代 `IF`**：Phase 0 证明 `IF_pct120` 极性为负（无效），而代表活跃资金风险偏好的 `IM_pct120`（上市前平滑回退至 `IC_pct120`）具有正动量（`≥75%` 记 `+1.0`，`≤15%` 记 `-0.5`）。
  2. **分红季绝对基差底线铁律（`ann >= -5.0%`）**：
     - **踩坑案例（`2026-09-22` & `2026-10`）**：每年 5~7 月 A 股集中分红，导致期指天然深度贴水（`-7% ~ -12%`）。到了 9~10 月分红结束后，即使 `IM` 依然深度贴水 **`-5.88%`**，对比过去 120 天也会冲上 `81%` 高分位被误判成利好！加上 **`年化基差 < -5.0% 时强行压回 0.0`** 的绝对底线护栏后，彻底消灭了分红季尾声假多头。

### 3.4 非对称确认缓冲（Hysteresis）与双空防单票铁律
- **非对称缓冲器（默认 `K=2` 日，低频档 `K=3` 日）**：
  - 好比空调温控器——不会因为室温从 `25.0℃` 抖动到 `25.1℃` 就每分钟开关压缩机。普通状态切换必须连续维持 `K` 个交易日才生效，直接把 5 年调仓次数从 **338 次压降到 104~167 次**，省掉巨额手续费和来回打脸。
  - **逃生门（非对称）**：一旦出现**周 K = 空 且 日 K = 空**的硬破位，**0 延迟当日立刻切空**，防止崩盘加速。
- **双空防单票推翻铁律**：
  - 当周 K 与日 K 已经双空共振时，**严禁单个非 ERP 因子一票把 `空` 软化成 `准备多`**（必须满足 `ERP Z ≥ +1.5σ` 或至少 2 路正向因子共振且确认分 `≥ +25`）。这条铁律在 `2026-09-22` 顶部完美守住 `空 (0%)`，躲开了后续 `-14%` 主跌浪。

## 四、L2 战术拐点：微观宽广度、阿姆氏与大阳线中轨

### 4.1 市场宽广度、涨额占比与额价差
- **涨家占比（宽广度）**：$\text{AdvRatio} = \frac{\text{上涨家数}}{\text{全市场有效家数}} \times 100\%$
- **涨额占比**：$\text{AdvAmtRatio} = \frac{\text{上涨股总成交额}}{\text{全A总成交额}} \times 100\%$
- **额价差（无奇点替代指标）**：$\text{Spread} = \text{AdvAmtRatio} - \text{AdvRatio}$
  - **直觉**：如果全市场只有 `20%` 的股票上涨，但这 `20%` 的股票吸走了 `55%` 的成交额（额价差 `+35pp`），说明资金极端抱团少数大权重硬撑指数（`WEIGHT_PROPPING` 托而不举），大多数个股在失血！

### 4.2 阿姆氏指数（TRIN / Arms Index）与数学奇点修正
- **经典公式（金额口径 `TRIN_额`）**：
  $$\text{TRIN}_{\text{额}} = \frac{\text{上涨家数} / \text{下跌家数}}{\text{上涨总成交额} / \text{下跌总成交额}} = \frac{\text{下跌股户均成交额}}{\text{上涨股户均成交额}}$$
  - **读数直觉**：
    - `TRIN < 0.85`：上涨股户均成交额远大于下跌股（资金主动抢筹进攻）；
    - `TRIN > 1.35`（且高宽广度）：上涨家数虽多，但下跌的少数大盘权重放巨量砸盘出货（`TOP_DIVERGENCE` 高位量价背离）。
- **⚠️ 本研究发现的“数学奇点”与位置护栏修正（三大真案例对比）**：
  - 当全市场普涨超过 `85%` 时，公式里的“下跌家数”趋近于 0，导致分子爆炸、`TRIN` 虚高，旧版系统把所有暴涨普涨日都错判成了 `TOP_DIVERGENCE`！
  - **修正方案**：同时看 `AdvRatio ≥ 85%`、`AdvAmtRatio ≥ 80%` 和 **MA20 乖离率**：

| 真实历史日期 | 涨家占比 | 涨额占比 | TRIN_额 | 偏离MA20 | 新版定性 | 随后 5 日沪深300 |
| :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| **`2021-02-18`** *(核心资产崩盘)* | `85.9%` | **`60.6%`** (<80%) | `4.288` | `+4.30%` | **`TOP_DIVERGENCE`**（真见顶出货！） | **`-5.18%`** |
| **`2024-10-08`** *(国庆冲顶暴走)* | `94.2%` | `89.6%` | `1.88` | **`+26.59%`** (>8%) | **`BLOWOFF_EUPHORIA`**（触发 50% 封顶护栏！） | **`-9.40%`** |
| **`2026-11-27`** *(底部放量V反)* | `96.5%` | `91.7%` | `2.609` | **`+1.31%`** (低位) | **`BROAD_SURGE_EXPANDING`**（健康普涨，修正奇点！） | 刚发生/待验证 |

### 4.3 麦克莱伦摆荡指标（MCL / MSI / 10日 ADR）
- **公式**：记每日净上涨家数 $N_t = \text{Up}_t - \text{Down}_t$，
  $$\text{MCL}_t = \text{EMA}_{19}(N_t) - \text{EMA}_{39}(N_t), \quad \text{MSI}_t = \sum \text{MCL}, \quad \text{ADR}_{10} = \frac{\sum_{10d}\text{Up}}{\sum_{10d}\text{Down}}$$
- **用法**：比原始涨跌家数折线平滑得多；**牛市中若周K仍多但 `MCL < -150`**，说明表面指数没跌但全市场个股已持续失血，是经典高位防补跌警报。

### 4.4 全 A 真中位数与极端左尾恐慌探针
- **为什么看“全 A 真中位数”而不是上证指数？** 上证指数受银行、“三桶油”权重绑架，经常“指数涨 +0.5%，但 4000 只个股在跌”。把全市场 5,300+ 只股票当日涨跌幅排成队，取正中间那只的涨跌幅就是**全 A 真中位数（`median_pct`）**——最真实反映普通股民体感。
- **极端左尾探针规则**：当大盘处于空仓防守期，一旦出现 **单日中位数 `≤ -4.0%`**、**5 日累计中位数 `≤ -8.0%`** 或 **`IC` 年化贴水 `≤ -25%`**，说明恐慌盘集中踩踏出清，L2 自动开启 **`40%` 有界试仓探针**（最长持有 10 个交易日，跌破入场点 `-5%` 硬止损）。
- **真实案例**：`2024-01-31`（3215 点）触发探针吃到 2 月微盘雪崩大底 `+8.53%`；`2026-11-20`（全A仅 5.6% 上涨）触发探针并在 `11-27` 吃到 `+4.17%` 反抽。

### 4.5 大阳线中轨（Anchor Midpoint）与精确 `3/4` 蓝灯
- **锚定大阳线定义**：科创 50 单日 `≥ +5%`、或创业板 `≥ +4%`、或上证 `≥ +2%`。
- **中轨公式**：
  $$\text{Midpoint} = \frac{\text{大阳线前一日收盘价} + \text{大阳线当日收盘价}}{2}$$
- **逻辑直觉**：突破大阳线的实体中点，代表当日抢筹主力的核心持仓成本区。随后 `T+1 ~ T+5` 回踩只要收盘稳守中轨上方，就是高胜率右侧低吸买点；一旦收盘有效跌破中轨，说明假突破，必须硬止损！
- **精确 `3/4` 蓝灯（实证铁律：严禁收紧为 4/4 AND！）**：
  1. 处于大阳线后 `T+1 ~ T+5` 验证期；
  2. 收盘稳守大阳线中轨上方；
  3. **满足其一即可（OR）**：双创 `TCR` 降温至 `25% ~ 37.5%` **或** 炸板率 `< 35%`。
  - *实证对比*：5 年首次触发 `3/4` 蓝灯（`n=34`）科创 50 未来 5 日均值 **`+2.33%`（盈亏比 `2.64`）**；强行收紧为 4/4 AND 反而亏 `-2.15%`；而跌破中轨后 5 日均值 `-2.07%`（止损极准）。

### 4.6 盘中成交额进度折算（供 `14:40` 尾盘执行）
- A 股全天交易共 **240 分钟**（`09:30~11:30` 为 120 分，`13:00~15:00` 为 120 分）。
- 盘中实时运行时（如 `14:40`，已开市 `220` 分钟），系统自动按 $\text{预估全天成交额} = \text{当前累计成交额} \times \frac{240}{\text{已开市分钟数}}$ 折算量比；**15:00 闭市后、周末或 Tushare 盘后源自动不折算（系数 `1.0`）**。

## 五、L3 双创风格拥挤度、纯观测指标与“证伪避坑清单”

### 5.1 双创拥挤度 TCR（Tech Concentration Ratio）
- **公式**：
  $$\text{TCR} = \frac{\text{创业板总成交额(300/301)} + \text{科创板总成交额(688/689)}}{\text{沪深两市总成交额}} \times 100\%$$
- **结构性漂移现象**：随着科创板/创业板扩容与 AI 科技时代到来，双创 TCR 中枢从 2021 年的 `24.8%` 一路抬升至 2026 年的 `40%` 附近，因此不能死板地用“TCR < 20% 才算冰点”（降温看 120 日分位 `≤10%`）。
- **王牌红灯组合：`TCR > 40%` 且 `放量 (量比 > 1.0)` 且 `双创滞涨 (科创50 < +0.5% 且 创业板 < +0.5%)`**：
  - 说明全市场超 40% 的资金全挤在科技股里放巨量却推不动股价——主力高位派发！
  - **实战神例（`2026-07-01`）**：当日 `TCR = 44.22%`、放量 `1.12` 倍、科创 50 收跌 `-2.48%`，L3 当晚强制把科创 50 仓位从 `100%` 压至 `30%`，**次日 `07-02` 科创 50 单日暴跌 `-7.70%`**，直接躲掉主杀！

### 5.2 纯观测指标（展示背景，权重 `0.0`，不参与 L1 投票）
- **19 只宽基 ETF 真实份额加权加仓指数**：用 $\Delta\text{份额} \times \text{净值}$ 衡量国家队/机构真金白银申赎，但 Phase 0 证明其条件加分器在 5 年全周期失效（60D `-2.15%`），故仅作参考面板。
- **全市场两融余额与 5 日变动率**：看杠杆资金加减仓趋势。
- **中美 10 年期国债利差与 60 日变化**：绝对倒挂水平与双创 TCR 存在伪共线（`r = -0.825`），仅关注 60 日利差显著走阔（`≥ +30bp` 偏顺风）。

### 5.3 ⚠️ 5 年回测“已证伪/避坑清单”（千万别再踩）
1. **两融出清弹性比值 $E_m = \Delta\text{Margin}_{5d} / \Delta\text{Index}_{5d}$**：**彻底证伪移除**。在 4 种指数分母下全部无效，90% 触发点是因为指数 5 日涨跌接近 0 造成分母爆炸的数学噪音。
2. **`VR20 > 250` 当顶部超买**：**原标签写反**。5 年实测 `VR20 > 250` 反而是强势动量（20D `+2.48%`，胜率 `68.5%`），仅 `VR20 < 70` 有弱超卖反弹参考。
3. **高管增减持 / 全A等权 PE / 恒生国企先行速率 / 牛市 ETF 赎回扣分**：典型“永熊偏置”因子，会导致系统在牛市里常年喊空踏空。

## 六、Phase 2 个股趋势与买前风控闸门

在 L1 大盘允许做多时，对任意候选股票执行五维买前体检，输出 **`✅ PASS` / `🟡 WATCH` / `⛔ VETO`**：

| 维度 | 核心指标与公式 | 实战意义 |
| :--- | :--- | :--- |
| **1. 多周期趋势** | 160 周线 + 日线一目均衡表/VW-MACD + `Close > MA20 > MA60 > MA120` | 确认股票自身处于上升通道，剔除周/日双空破位弱票。 |
| **2. 相对强弱（RS Alpha）** | $\text{RS}_{20} = R_{\text{个股},20d} - R_{\text{基准},20d}$（对比沪深300及所属板块科创50/创业板） | 只买跑赢大盘和板块的真龙头（如 `RS20 > +3%`），不买滞涨补跌跟风股。 |
| **3. 形态与追高红灯** | 个股大阳线中轨回踩 / 回踩 MA10-20 / **VCP（近5日 ATR ÷ 近20日 ATR `≤ 0.72` 波动极致收敛）**；**偏离 MA20 `> +12%` 一票 `VETO`** | 买在“缩量回踩蓄势点”，坚决拦截爆拉远离均线的追高接盘。 |
| **4. 资金与 ETF 防火墙** | 1D/3D/5D 主力资金净流入（亿元）与 5D **DDX**（主力净流入 ÷ 流通市值）；**严禁对 ETF 计算 DDX** | 确认主力真金白银沉淀，且防止 ETF 做市商申赎机制误导 DDX。 |
| **5. 结构止损、盈亏比与大盘耦合** | **ATR14**（14日平均真实波幅）；止损价取 `max(10日低点, Close - 2×ATR14, 大阳线中轨)`；盈亏比 $R:R = \frac{\text{目标涨幅}}{\text{止损距离}}$（门槛 `≥ 1.8`）；**单票仓位上限随 L1 大盘仓位动态缩容（大盘 `0%` → 强制 `VETO`）** | 先算清楚“错了亏多少、对了赚多少”，并且绝不逆着大盘大势硬干个股。 |

## 七、量化回测绩效指标速查表

看懂本仓库 `reports/` 里的两份回测审计报告，只需掌握下面 8 个核心指标：

| 指标 | 公式 / 含义 | 怎么看算好？ |
| :--- | :--- | :--- |
| **CAGR（年化复合收益率）** | $(\text{期末净值})^{242 / N} - 1$（A股每年约 242 交易日） | 衡量长期复利赚钱速度。 |
| **MDD（最大回撤）** | 历史任意高点到其后最低点的最大跌幅百分比 | 决定你拿不拿得住。沪深300 5年 MDD `-45.6%`，Cockpit 压到 `-27.7% ~ -32.8%`。 |
| **Sharpe（夏普比率）** | $\frac{\text{年化收益} - R_f}{\text{年化波动率}}$（每承担 1 份总波动换来多少超额收益） | 越高越好；OOS 区间 Cockpit `K=2` 达 `+0.495`，显著高于 BuyHold `+0.300`。 |
| **Sortino（索提诺比率）** | $\frac{\text{年化收益} - R_f}{\text{年化下行波动率}}$（只惩罚向下暴跌，不惩罚向上暴涨！） | 比夏普更贴合真实投资体感；OOS Cockpit 达 `+0.648`（BuyHold 仅 `+0.323`）。 |
| **Calmar（卡玛比率）** | $\text{CAGR} / |\text{MDD}|$ | 衡量收益与最大痛感（最大回撤）的性价比。 |
| **胜率（WR）与盈亏比（P/L）** | $\text{WR} = \frac{\text{盈利次数}}{\text{总次数}}$；$\text{P/L} = \frac{\text{平均盈利}}{\text{平均亏损}}$ | 交易核心看**期望值** $= \text{WR} \times \text{均盈} - (1-\text{WR}) \times \text{均亏}$；哪怕胜率 53%，只要盈亏比 `2.6`（如 3/4 蓝灯），长期就是印钞机。 |
| **Rank IC 与 Newey-West `t` 值** | 因子排序与未来收益排序的斯皮尔曼相关系数（Rank IC）；Newey-West 用于修正 20D/60D 重叠收益窗口导致的虚高 `t` 值。 | 绝对值 `> 0.05` 且同向跨体制稳定即有价值，`|t_NW| > 1.96` 达 95% 统计显著（如 Cockpit 确认分 60D OOS IC = `+0.2623`, `t = +2.14`）。 |
| **交易摩擦（bps）与 `C→C` / `O→O`** | `10bps = 0.10%`（覆盖印花税+佣金+滑点）；`Close→Close` 对应尾盘 `14:45` 执行，`T+1 Open→Open` 对应盘后复盘次日 `09:30` 开盘执行。 | 只有扣完双边 10bps 且在 `O→O` 口径下依然大幅跑赢基准，策略才具备真实实盘生命力。 |
