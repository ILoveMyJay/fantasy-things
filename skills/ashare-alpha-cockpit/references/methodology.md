# `ashare-alpha-cockpit` 实证方法论与规则手册

## 1. 实证回测依据（5 年零未来数据 + Walk-Forward 样本外验证）

本引擎所有因子取舍、权重与风控门禁均来自 `2021-01-04 ~ 2026-11-27`（1,430 交易日）零未来数据因果回测（Phase 0）及 `2021–2023` IS → `2024–2026` 严格 OOS 盲测：

- **确认分 IC 质变**：纠偏后的 `Cockpit_Confirm` 60D Rank IC 在 IS (`+0.2110`) 与 OOS (`+0.2623`, `t=+2.14`) 双体制均为正，显著超越原版 Compass v2（5Y `-0.0593`）。
- **参数高原稳健**：确认缓冲期 `K ∈ {2, 3, 5}` 在 OOS 收益均落在 `+14.78% ~ +16.47%` 平坦高原，调仓次数较原版（338次）腰斩 50%~70%。
- **沪深 300 样本外绩效（10bps 双边摩擦）**：`S4a_CockpitV1_K2` 严格 OOS 收益 `+23.84%`（Sharpe `+0.495`, Sortino `+0.648`, MDD `-15.38%`, 81 次调仓），同时在最严苛盘后实盘口径（`T+1 Open→Open`）5 年跑赢原版 `+23.24pp`。

| 因子 | 处置 | 实证依据 |
| :--- | :---: | :--- |
| 周/日 一目均衡表 + VW-MACD | **保留核心轴** | 主趋势与择时骨架，配合 `K=2/3` 非对称缓冲降噪 |
