# A股四层多空指标罗盘 v2（A-Share Market Compass）

本技能将「**周K主趋势轴（一目均衡表 + VW-MACD） × 日K时机阀 × 去偏确认分（非对称 ERP + 50/300 PCR + 纯净 IF 基差 120日分位 + 宽基 ETF 底部条件加分） → 四态决策（多 / 空 / 准备多 / 准备空）**」体系工程化为本地零造假量化引擎，支持**每日盘后复盘**、**盘中实时拆量监控屏**与**本地 SQLite 历史台账积累**。

> **v2 核心升级（经近 2 年严格零未来数据 IS/OOS 盲测验证）**：
> - 彻底移除已证伪或存在严重永久看空偏置/共线冗余的 3 项指标：**高管增减持、全A等权 PE、恒生国企(HSCEI)先行速率**。
> - 股指期货年化基差引入**交割前 ≤5 天自动滚仓次月 + 120日滚动分位**，消除交割周爆表与常态对冲贴水偏置。
> - 19 只宽基 ETF 份额改为**条件底部加分器**（仅在 `≥70轨 且 日K翻多` 时加分），不再对牛市上涨期的正常兑现赎回做空头惩罚。
> - 微观拆量层（`TRIN_额` / `MCL`）定位于**熊市假反弹拆穿（`WEIGHT_PROPPING`/`FAKE_REBOUND`）与牛市个股失血预警（`MCL < -150`）**，支持通过本地 Tushare Pro 一键回填历史 `TRIN_额 / MCL` 底座。

## 核心铁律（严禁违背）

1. **零虚假数据**：任意外部接口超时或返回异常时，脚本严格返回 `None` 并在报告顶部「缺失数据明示」中列示，严禁使用硬编码默认值伪造结论。
2. **绝不单看 TRIN 数值大小**：必须结合「宽广度（涨家占比）× 额价差 × 周K趋势阶段 × MCL」交叉判读；牛市中单日小票普涨触发的 `TOP_DIVERGENCE` 不得机械推翻主趋势。
3. **50 PCR 领先于 300 PCR**：若 300 PCR 击穿下轨而 50 PCR 未破，必须提示假底风险；QVIX/IV 仅作期权成本参考，绝不用于预测大盘涨跌。
4. **宽基 ETF 只看官方份额变化，不看成交量**：且须牢记其天然逆势托底属性，仅作底部右侧共振加分。
5. **大小周期冲突必落「准备态」**：周K与日K或去偏确认分发生显著冲突时，输出 `准备多` 或 `准备空` 控制风险，等待共振。

## 标准执行工作流

> 以下命令默认在 `ashare-market-compass` 技能根目录下执行。

### 1. 日常盘后 / 实时全景研判（默认）
```powershell
python scripts/run_compass.py --mode daily --format markdown
```
执行完成后，直接呈现四层量化仪表盘，并基于以下四问给出清晰的方向结论：
- **主趋势轴（周K/日K技术面）**：上证与沪深 300 的周 K（主趋势）与日 K（时机阀）在一目均衡表、VW-MACD、布林带与 CCI 上是否共振？同时查看独立的**双创科技风格子面板（创业板指 / 科创 50）**判断科技成长相对强弱（不干扰总仓位）。
- **去偏确认层（估值 + 衍生品 + ETF 共振）**：非对称 ERP、纯净 IF 基差 120 日分位、50/300 PCR 共振、19 只宽基 ETF 底部条件加分是否发出顶部预警或底部共振？
- **短线拆量与宽度层**：今日 `TRIN_额` 四象限与 `MCL` 是否提示熊市假反弹/抱团托而不举，或牛市中的个股失血（`MCL < -150`）？
- **四态行动纪律**：明确告知当前处于 `多` / `空` / `准备多` / `准备空` / `观望(中性)`，不预测具体底部点位，只列明“距离真正共振还差哪几项条件”。

### 2. 盘中每分钟实时拆量监控屏（复刻命令行实盘屏）
```powershell
python scripts/run_compass.py --mode watch --interval 60
```

### 3. 历史底座回填与查看决策台账
```powershell
# 回填近 60 个交易日的全A宽度/TRIN(Tushare)、140日纯净期指基差、上交所宽基ETF份额与官方期权PCR
python scripts/run_compass.py --mode backfill --days 60

# 查看历史四态决策台账（同步导出至 data/decision_ledger.csv）
python scripts/run_compass.py --mode ledger
```
