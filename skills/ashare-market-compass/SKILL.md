# A股四层多空指标罗盘（A-Share Market Compass）

本技能将「**资金面定大势（洋流） × 技术面定时机（小势） → 四态决策（多 / 空 / 准备多 / 准备空）**」体系工程化为本地零造假量化引擎，支持**每日盘后复盘**、**盘中实时拆量监控屏**与**本地 SQLite 历史台账积累**。

## 核心铁律（严禁违背）

1. **零虚假数据**：任意外部接口超时或返回异常时，脚本严格返回 `None` 并在报告顶部「缺失数据明示」中列示，严禁使用硬编码默认值伪造结论。
2. **绝不单看 TRIN 数值大小**：必须结合「宽广度（涨家占比）× 额价差 × 中期趋势阶段」四象限交叉判读。
3. **50 PCR 领先于 300 PCR**：若 300 PCR 击穿下轨而 50 PCR 未破，必须提示假底风险；QVIX/IV 仅作期权成本参考，绝不用于预测大盘涨跌。
4. **宽基 ETF 只看份额变化，不看成交量**：使用 19 只核心宽基 ETF 的官方真实份额净变动 × 净值计算加权加仓速率（30/70 轨），彻底规避成交量对敲噪音。
5. **大小周期冲突必落「准备态」**：资金面偏空而技术面反弹时，强制输出 `准备空`（零仓位等待共振），绝不为顺小势而逆大势。

## 标准执行工作流

> 以下命令默认在 `ashare-market-compass` 技能根目录下执行。

### 1. 日常盘后 / 实时全景研判（默认）
```powershell
python scripts/run_compass.py --mode daily --format markdown
```
执行完成后，直接呈现四层量化仪表盘，并基于以下四问给出清晰的方向结论：
- **大势层（洋流）**：ERP 标准差轨、等权 PE 分位、19 只宽基 ETF 加权加仓指数（30/70 轨）、高管增减持、恒生国企速率、期指升贴水、50/300 PCR 共振是否一致？
- **短线拆量层**：今日属于「高位量价背离 / 假反弹空头回补 / 抱团托而不举 / 真冰点候选 / 放量普涨进攻」哪一象限？
- **技术面层**：上证与沪深 300 的周 K（大势）与日 K（时机）在一目均衡表、VW-MACD、布林带与 CCI 上是否共振？
- **四态行动纪律**：明确告知当前处于 `多` / `空` / `准备多` / `准备空` / `观望(中性)`，不预测具体底部点位，只列明“距离真正反转还差哪几项条件”。

### 2. 盘中每分钟实时拆量监控屏（复刻命令行实盘屏）
```powershell
python scripts/run_compass.py --mode watch --interval 60
```

### 3. 历史底座回填与查看决策台账
```powershell
# 回填近 30 个交易日的宽基 ETF 官方份额与 SSE/SZSE 期权 PCR
python scripts/run_compass.py --mode backfill --days 30

# 查看历史四态决策台账（同步导出至 data/decision_ledger.csv）
python scripts/run_compass.py --mode ledger
```
