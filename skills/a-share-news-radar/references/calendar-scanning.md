# 日历事件监测规则

用于盘前预期扫描（Phase 1）时，系统性地发现未来 1-3 个交易日的确定性事件。

## 监测维度

### 1. 航天发射

搜索关键词：
- 「火箭 发射 计划」「卫星 发射 日期」「长征 发射 计划」
- 各型号：长征二号/三号/五号/七号/八号/十号/十一号等
- 商业火箭：星河动力、蓝箭、星际荣耀、天兵科技等

A 股映射：
- 航天军工：航天电子、航天电器、航天彩虹、中航光电等
- 商业航天：中国卫星、中国卫通、航天宏图、中科星图等
- 发射服务：航天动力、航天科技集团旗下上市公司

### 2. 重大会议/论坛

搜索关键词：
- 「明日 会议 议程」「本周 峰会」「经济 数据 发布」
- 「国务院 常务会议」「发改委 会议」「央行 货币政策委员会」
- 「人工智能 大会」「新能源汽车 论坛」「半导体 峰会」

A 股映射：
- 会议主题决定方向，如 AI 大会 → AI/算力/应用
- 政策类会议 → 对应扶持行业

### 3. 政策发布窗口

搜索关键词：
- 「本周 政策 发布」「产业 政策 即将 出台」
- 「新能源 补贴 政策」「芯片 扶持 政策」
- 「汽车 以旧换新」「家电 补贴」「地产 政策」

A 股映射：
- 按政策领域匹配对应板块

### 4. 新品发布

搜索关键词：
- 「新品 发布会 日期」「产品 发布 时间」「手机 发布」
- 「华为 发布会」「苹果 发布会」「小米 发布会」
- 「新能源汽车 新车 发布」「智能驾驶 发布」

A 股映射：
- 发布会主题决定受益方向（如华为链、苹果链、汽车链）

### 5. 财报/业绩

搜索关键词：
- 「业绩预告 截止 日期」「财报 披露 时间」「一季报 预约」
- 「中报 预约 披露」「年报 披露」
- 行业龙头业绩预告发布

A 股映射：
- 超预期/低于预期带动板块联动
- 注意密集披露期的板块情绪影响

### 6. 行业展览/博览会

搜索关键词：
- 「车展 日期」「航展 日期」「行业 博览会」
- 「中国国际 进口博览会」「广交会」「服贸会」
- 「消费电子展」「半导体展」「新能源展」

A 股映射：
- 展览期间相关板块可能获得主题关注
- 展会上发布的新品/合作是关注点

### 7. 指数样本股调整

搜索关键词：
- 「指数 样本股 调整 生效 日期」「沪深300 调入 调出」
- 「中证 指数 定期 调整」「上证50 调整」

A 股映射：
- 调入：被动资金配置，短期利好
- 调出：被动资金撤出，短期承压
- 生效日前 1-2 天可能已有提前反应

### 8. IPO / 限售股解禁

搜索关键词：
- 「新股 申购 日期」「新股 上市 时间」
- 「限售股 解禁 日期」「解禁 市值」

A 股映射：
- 大额解禁：相关个股承压
- 热门新股上市：可能带动板块情绪

### 9. 重要经济数据发布

搜索关键词：
- 「CPI 公布 时间」「PPI 数据」「PMI 数据」
- 「社融 数据」「信贷 数据」「进出口 数据」
- 「GDP 数据」

A 股映射：
- 超预期/低于预期影响宏观方向
- 结构数据（如社融结构）决定具体板块

### 10. 国际贸易/地缘事件

搜索关键词：
- 「关税 调整 日期」「贸易 谈判 时间」
- 「制裁 生效 日期」「出口 管制」

A 股映射：
- 按具体行业和公司评估

## 搜索策略

1. **时间范围**：搜索「2026年7月 航天 发射」格式，锁定具体日期
2. **交叉验证**：用多个关键词验证同一事件，确认日期
3. **来源优先级**：官方公告 > 权威媒体 > 行业媒体 > 自媒体
4. **标注清晰**：每个事件标注「已确认：来源链接」或「待确认：仅有传闻」

## 输出格式

每个识别的事件，输出结构：

```
事件名称：[名称]
日期：[YYYY-MM-DD]（已确认/待确认）
来源：[来源链接]
类型：[航天/会议/政策/新品/财报/展览/指数/IPO/经济数据/地缘]
确定性：高/中/低
A股映射方向：[主题/行业]
```
