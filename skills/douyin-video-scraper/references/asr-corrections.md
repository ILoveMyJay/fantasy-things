# ASR 专有名词错词校正表

ASR 对专有名词、术语、人名的错误率高，成文前必须过一遍。以下为财经/科技类视频实测错例。

## 金融 / 技术分析

| ASR 误识 | 正确 |
|---|---|
| 阿姆式 / 阿姆士 | 阿姆氏（TRIN，Arms Index） |
| 唐西安 | 唐奇安（Donchian） |
| 一区魔窟 | 一目均衡表（Ichimoku） |
| 认股 / 正沽 | 认沽 |
| max 恐慌指数 | VIX 恐慌指数 |
| TRIN 额 / TRIN 量 | TRIN额 / TRIN量（资金流向 TRIN） |

### 关键公式（易被 ASR 破坏，务必手工核对）

```
TRIN = (上涨家数 ÷ 下跌家数) ÷ (上涨成交额 ÷ 下跌成交额)
```

TRIN额 < 1 表示资金强于宽度。相关程序字段：TRIN额、TRIN量、涨家占比、涨额占比、额价差、量价差。

## 校正方法

1. 转写完成后，用领域词典做全局替换（上表可直接作为替换表）；
2. 对高频术语用正则批量替换，注意大小写与中英文混排；
3. 涉及公式、数值、公司名称的片段，回到关键帧截图人工核对一遍——ASR 可能把数字也识错；
4. 校正只改错词，不改写口播原意；逐字稿保留口语重复词，成文稿再去芜。

> 这份表是按博主领域累积的。采集新领域博主时，把新发现的错例追加进来。
