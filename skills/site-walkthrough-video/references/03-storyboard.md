# 03 — 分镜设计

视频分为两段：**导航段**（模拟用户操作）和**详情段**（展示目标页面内容）。

## 导航段分镜

### 标准交互模式（每次点击都遵循）

```
镜头 N：页面加载 → 向下滚动 → 向上滚动居中目标 → 光标移入 → 点击 → 切换
```

| 时间 | 动作 | 视觉 |
|------|------|------|
| 0-0.3s | 页面淡入 | 页面截图从 opacity 0→1 |
| 0.3s | 滚动提示出现 | 右下角"↓ 向下滚动浏览"胶囊 |
| 0.3-滚动结束 | 匀速向下滚动 | 页面 y: 0 → -maxScroll，ease: none |
| 底部停留 | 0.5-1s | 页面静止，展示底部内容 |
| 提示切换 | "↑ 向上滚动定位" | 文字替换 |
| 向上滚动 | 页面 y: -maxScroll → -targetY | ease: power1.inOut，目标卡片居中 |
| 提示消失 | opacity 0 | |
| 光标移入 | 光标从角落移动到卡片中心 | ease: power2.inOut，0.7s |
| Hover | 光标微调 10-20px | ease: sine.inOut，0.3s |
| 点击 | 涟漪扩散 scale 0→8 | 0.6s，power2.out，暖橙色 |
| 切换 | 页面淡出 opacity 1→0 | 0.4s |

### 导航段时长估算

- 单次点击（含滚动）：约 8-12 秒
- 2 次点击（首页→分类→详情）：约 15-20 秒
- 滚动距离越长，耗时越多（速度固定 ~430px/s）

## 详情段分镜

从标准镜头库中选择 4-6 个镜头，每个镜头 4-8 秒。

### 标准镜头库

| 镜头 | 适用场景 | 视觉元素 |
|------|----------|----------|
| **登场** | 任何详情页开场 | 大标题 + 副标题 + 主图 + 关键数据（2-3 个） |
| **图鉴/要点** | 有多个部位/功能/特点 | N 个编号圆点依次点亮，对应图片/文字 |
| **深潜** | 重点展示 1-2 个核心内容 | 大图微距特写 + 扫描线动效 + 详细说明 |
| **轮播** | 快速展示多个条目 | 卡片左右切换，每个 1-1.5s |
| **数据** | 有统计数据 | 数字从 0 滚动到目标值 + 进度条 |
| **CTA** | 结尾召唤行动 | 按钮 + 进度条 0→100% + 品牌 Logo |

### 详情段时长估算

- 每个镜头 4-8 秒
- 5 个镜头约 25-40 秒
- 旁白驱动时长：先写文案，生成语音后按实际时长调整镜头

## 分镜文档模板

```markdown
# STORYBOARD

## 导航段（18s）

### 镜头 1：首页 → 陆地探险（0-8s）
- 页面：首页截图
- 滚动距离：55px（页面较短）
- 目标卡片："陆地探险"，居中位置 (1270, 410)
- 点击时刻：4.8s

### 镜头 2：陆地探险 → 非洲象（8-15.5s）
- 页面：陆地页完整长图
- 滚动距离：2787px
- 目标卡片："非洲象"，居中位置 (480, 540)
- 点击时刻：12.5s

### 镜头 3：过渡（15.5-18s）
- 推镜到非洲象主图，scale 1.15→1.0

## 详情段（33s）

### Beat 1：登场（0-6s）
- 标题：非洲象 / African Elephant
- 拉丁名：Loxodonta africana
- 数据：肩高 3.2-4m / 体重 4-7吨 / 冲刺 40km/h

### Beat 2：图鉴（6-12s）
- 10 个解剖部位编号圆点依次点亮
- ...
```

## 注意事项

- 先写旁白文案，生成语音后按实际时长调整分镜（语音是时长的 ground truth）
- 导航段的滚动距离取决于页面高度，用完整长图的高度计算
- 详情段的每个镜头必须有视觉运动，不能是静态图片（至少有 Ken Burns 缓慢缩放）
- 总时长控制在 60 秒以内适合社交媒体
