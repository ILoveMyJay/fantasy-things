# 04 — 语音生成

使用本地 edge-tts，零成本、零 API Key、高保真。

## 快速生成

```bash
python scripts/generate_vo.py \
  --text "非洲象是陆地上体型最大的哺乳动物。" \
  --out project/narration.mp3
```

或直接调用 edge-tts runner：

```bash
python E:/aicode/antigravity/lingokids-2d/.agents/skills/edge-tts/scripts/edge_tts_runner.py \
  --text "你的旁白文案" \
  --voice "zh-CN-XiaoxiaoNeural" \
  --rate "-4%" \
  --pitch "+2Hz" \
  --out "project/narration.mp3"
```

## 推荐参数

| 参数 | 值 | 说明 |
|------|-----|------|
| voice | `zh-CN-XiaoxiaoNeural` | 温暖女声，少儿科普首选 |
| rate | `-4%` | 稍慢，清晰 |
| pitch | `+2Hz` | 稍高，活泼 |
| 英文 voice | `en-US-AnaNeural` | 甜美女声，适合双语 |

## 文案精简方法

目标时长 = 字数 ÷ 4.5（中文约 4-5 字/秒）

| 目标时长 | 字数 |
|----------|------|
| 20s | ~90 字 |
| 30s | ~135 字 |
| 40s | ~180 字 |

**精简步骤：**
1. 先写完整文案，数字数
2. 生成测试音频，测量实际时长
3. 如果超时，优先删除修饰性形容词，保留核心名词和动词
4. 每段旁白之间留空行（约 0.6s 停顿），对应分镜的镜头切换
5. 重新生成，直到时长匹配

## 转为 wav（hyperframes 要求）

```bash
ffmpeg -i narration.mp3 -ar 44100 -ac 1 narration.wav
```

hyperframes 渲染需要 44100Hz 单声道 wav 格式。

## 保存文案

将最终旁白文案保存为 `narration.txt`，方便后续重新生成或换音色。
